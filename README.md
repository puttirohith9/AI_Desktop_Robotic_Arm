# AI Desktop Robotic Arm

A 3D-printed desktop robotic arm integrating ROS 2, Python, computer vision, SolidWorks, motion planning, and artificial intelligence.

## Planned Capabilities

- Multi-joint robotic-arm movement
- ROS 2 control
- MoveIt 2 motion planning
- Camera-based object detection
- Voice-command interaction
- AI-assisted task planning
- SolidWorks design and stress analysis
